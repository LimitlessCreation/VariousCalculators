# VariousCalculators

新增了基础的矩阵计算器，有C程序文件版和（在windows上的）可执行文件版。
这样的话只要有编译器就可以了……或许吧。
可以进行矩阵加法，乘法，初等变换，转置，计算矩阵的秩、矩阵的逆，等等。能精确到小数点后4位。
这样就能应付一些线性代数作业，对于一些学高等代数的同学们好像没那么有用，毕竟它暂时还不会做证明题。
